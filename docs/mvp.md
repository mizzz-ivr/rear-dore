# レアどれ？ MVP

## 目的

登録不要で30秒程度で遊べる、少数派予測型のデイリー選択ゲームを提供する。

## MVPで実現すること

- 固定された5問を1問ずつ表示する
- 各問題で4〜5択から1件を選ぶ
- 回答確定後にのみ選択率と分布を表示する
- 選択率からレア度と得点を計算する
- 5問終了後に合計得点と称号を表示する
- Web Share APIまたはX投稿画面から結果を共有する
- スマートフォンで片手操作できる

## MVPの対象外

- ユーザー登録とログイン
- 回答のサーバー保存
- 実回答からのリアルタイム集計
- 管理画面
- ランキング
- コメントとフレンド機能
- 課金

## 責務分離

- `app/page.tsx`: ゲーム進行と画面状態
- `lib/game.ts`: 問題データ、レア度・得点・称号の判定
- `app/globals.css`: 共通の見た目と操作状態

将来DBへ切り替える場合も、スコア計算をUIから分離したまま維持する。

## 受け入れ条件

- 未選択状態では回答確定できない
- 回答確定後は選択肢を変更できない
- 回答前に分布が表示されない
- 5問を最後まで完走できる
- レア度境界値の単体テストがある
- `https://reardore.ivrm.jp`をmetadataと共有URLの基準にできる
- CIでlint、型チェック、単体テスト、本番ビルドを実行する
