# テーマコレクション

## 概要

`/collection`では、デイリーで一度でも遊んだテーマをコレクションとして表示します。未発見テーマはタイトルを公開せず、`？？？`として表示します。

## 保存方針

テーマ発見状態は`rear-dore:theme-collection`へ保存します。保存対象は`questionSetId`と初回発見日の`discoveredOn`だけです。テーマ名や問題内容は保存せず、現在の問題データから解決します。

同じテーマを再プレイしても最も古い発見日を保持します。プレイ履歴は最大30日ですが、コレクションは別保存のため、履歴から古い記録が消えても発見状態は維持します。既存ユーザーについては、現在残っているプレイ履歴から発見状態をバックフィルします。

不正なJSON、未知の問題セットID、不正な日付、重複データは読み込み時に正規化または除外します。コレクション保存に失敗しても、デイリーの履歴保存・実績・共有処理は継続します。

## 問題コンテンツ

問題は10テーマ・50問です。新規テーマは次の3つです。

- 仕事・学校編
- 休日・趣味編
- 未来・テクノロジー編

2026年8月14日までの出題対応は変更しません。2026年8月15日から次の10日周期へ切り替えます。

1. 仕事・学校編
2. 休日・趣味編
3. 未来・テクノロジー編
4. 究極の選択編
5. デジタル生活編
6. 食べもの気分編
7. おでかけ編
8. ちょっと変な日常編
9. もしも編
10. 日常のクセ編

新規3テーマは`lib/additional-question-sets.ts`で管理します。ローテーションは問題配列の長さではなく、明示した問題セットIDで固定します。

## テスト方針

- 全10テーマ・50問を既存の問題検証器で確認する
- 2026年8月14日までの既存割当を維持する
- 2026年8月15日以降の10日周期を確認する
- 10日問題周期と7日ミッション周期の最小公倍数70日について、すべての組み合わせで当日ミッションが理論上達成可能か確認する
- コレクションの復元、バックフィル、初回発見日維持、未知ID・不正日付除外を確認する

## 制約

コレクションはブラウザローカルの表示用データです。アカウント同期、別端末同期、改変防止、達成証明には利用しません。ブラウザデータを削除すると発見状態も失われます。
